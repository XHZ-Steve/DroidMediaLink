# 流体补光与光学玻璃调整 · 2026-11-15

## 实现

- 背景光场以连续指数映射替代覆盖率硬截断，光源衰减可独立柔化。补光按覆盖缺口分配能量，使用不同位置的封面主色、辅助色和强调色，避免整体灰色遮罩或单色提亮。
- 外观 → 环境背景新增「光场柔化」「流体补光」「补光强度」；展开高级参数可调「补光范围」。全部支持实时预览、范围校验、作用域覆盖、导入导出及分组重置。
- 光场柔化调整解析光源的衰减曲线；扩散半径调整光源范围；玻璃模糊只调整玻璃表面的采样。背景仍以原生分辨率渲染，保留静态亚像素抖动。
- 外观预设新增「通透光学」：降低染色和散射，提高折射、色散及方向性边缘高光。
- 复用 Apache-2.0 shayann07/liquidglass Qt 实现。在折射位移经过零点的边缘肩部保留沿法线的真实 RGB 背景采样分离，增加细节采样占比；不绘制彩虹描边，不增加离屏纹理。修改记录见 vendor/liquidglass/UPSTREAM.md。
- 主页和设置共用 GlassDialog，覆盖重置、清理缓存、预设保存/删除及现有连接确认弹窗。保留 Qt DialogButtonBox 的确认/取消角色、Esc 和键盘焦点，高对比模式使用降级表面。
- 托盘与快捷键子项改为操作名称，保留原设置键和绑定。

## 本机验证

- MinGW / Qt 6.11.1 构建通过。
- 六组 CTest 全部通过，44.93 秒；包括新增预设持久化、参数越界拒绝和确认框取消操作检查。最终窗口无障碍绑定及材质保护调整另跑 core/QML 回归。
- 实际运行截图：artifacts/fluid-glass/{fill-on,fill-off,confirm,settings,light}.png。采用隔离配置和固定媒体/歌词/封面输入，用于材质与布局检查；不是手机实机播放或联网封面匹配结果。
- 固定空白底部区域补光开启/关闭的平均编码亮度分别为 97.23 / 83.73（8-bit sRGB 加权值），说明补光产生实际像素变化。此值不是物理照度测量。
- 150% DPI 连续快速调整 240 次窗口尺寸：1084 次材质尺寸检查、0 错位、Dock 最大中心误差 0.5 逻辑像素、背景相邻通道最大跳变 1；542 帧，帧间隔 P95 13.38ms。约 329.6 MiB 工作集，包含截图读回的压力测试占一个逻辑核约 37.7%，隐藏后约 0.78%。数据来自 resize/resize-report.json，非所有硬件的性能保证。
- 图案背景硬件光学测试验证真实折射、隐藏源采样及标准材质回退；记录在 artifacts/liquidglass-hardware-smoke.log。
- 中英文资源和通信协议静态检查通过。本轮无 Android 或通信协议修改。

## 当前配置与限制

- 修改前的本机外观配置单独备份到 artifacts/fluid-glass/appearance-before.json，不含配对身份或网络凭据，不提交到仓库。
- 仅调整本机外观项：通透光学预设、光场柔化/补光，以及过小的扩散半径；保留设备、快捷键、歌词、连接等配置。
- 玻璃色散来自实际背景差异，在纯色或十分平缓的区域自然较弱；有光色变化或图案边界时更明显。本轮不读取 Windows 桌面图像，不添加人工彩虹描边。
- 本轮未做手机实机回归；本地测试覆盖媒体、歌词、封面引擎与 UI，既有通信代码保持不变。

# Windows preview7 验证记录

日期：2026-11-19。未发布或覆盖 GitHub Release。

## 实际修改

- 长句滚动终点增加末尾一个字符的余量；主窗口和桌面歌词均可开启“跟随逐字时间滚动”。每句只拟合两个控制点，整句使用单条连续单调曲线，暂停和跳转使用相同时间轴。
- 原译间距范围为 -50～50，主页和桌面歌词均可调整。负值实际影响文字位置；修复零高度容器被 Column 跳过的问题，桌面歌词焦点按原文和译文的联合边界居中，罗马音不改变该焦点。
- 窄色域高饱和封面才启用有限降饱和和局部黑白补光。92%以上有效彩色采样需集中在主色±21.6°内；主色饱和度超过.65、有效彩色采样占比超过10%才触发。丰富配色、中性封面修正强度为0，不更改原有取色结果。
- 外观 → 主题与配色提供预设选择、另存为、重命名、删除；保存所有材质作用域、继承关系及外观选项，支持随设置导入导出，最多50个自定义预设。删除有确认，满容量明确反馈。
- 增加桌面歌词真实屏幕合成诊断，比较 Qt 透明像素与屏幕背景，而非只检查 grabWindow 的 alpha。

## 已执行验证

- Qt 6.11.1 / MinGW Release 构建通过，shader GLSL/HLSL/MSL 编译通过。
- 六组 CTest 全部通过，54.10秒；涵盖逐字曲线的单调连续性、负间距及居中、预设作用域恢复/导入导出/容量上限。
- 资源与协议检查通过，diff空白检查通过。
- 首次显示、重开和穿透的透明屏幕采样分别2578、2590、2837点全部与背景一致。自然启动、背景开启、半透明和初始锁定等变体也留有本地诊断记录。
- 实际运行捕获外观预设、主页、双语歌词截图。截图为隔离测试夹具，不代表手机当前播放，也不是封面匹配准确性证据。
- Luna进行代码审查，修正预设容量上限和保存失败反馈；当前模型列表不再提供Luna后，Terra进行截图审查。预设控件无重叠截断，双语左对齐且无重叠。长句截图处于滚动中途，边缘裁切为单行滚动容器预期。
